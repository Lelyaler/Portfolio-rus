Обо мне

Frontend-разработчик с трёхлетним опытом в веб-разработке. Специализируюсь на WordPress и фронтенде на React.

Технологии осваивала самостоятельно и сразу применяла на практике. Развиваюсь во фронтенд-разработке, системно использую прикладной AI как вспомогательный инструмент в работе.

Работала в MaxBitSolution (iGaming, резидент ПВТ) в SEO-отделе: разрабатывала адаптивные интерфейсы, создавала и кастомизировала темы и плагины WordPress. Писала кастомные темы на объектно-ориентированном PHP (WP_Query, $wpdb, Composer PSR-4) с разделением логики, данных и шаблонов. Создавала блоки и паттерны Gutenberg, работала с REST API и PHP-хуками.

Отдельное направление - производительность и техническая часть SEO: после оптимизации Core Web Vitals проекты стабильно в зелёной зоне Google, а Schema.org (JSON-LD) дал рост переходов из поиска за счёт rich snippets.

Беру проекты на фрилансе - делаю сайты «под ключ» для малого и среднего бизнеса. Создаю кастомные темы WordPress и магазины WooCommerce с нуля, без готовых шаблонов и конструкторов. Подключаю платёжные API, обеспечиваю веб-безопасность (валидация, экранирование, защита от XSS и SQL-инъекций). Разрабатываю проекты на React, верстаю из Figma с Pixel Perfect и Mobile First.

Могу закрыть задачи на стыке WordPress и фронтенда - от кастомной темы до React-компонента. Ускорю существующие проекты за счёт оптимизации производительности. Возьму на себя техническую SEO-часть фронтенда: разметку, индексацию, Core Web Vitals. Доведу задачу от анализа до деплоя через GitLab CI.

HTML и CSS: семантический HTML, методология БЭМ, mobile-first подход, чистый и поддерживаемый код.

JavaScript: работа с DOM, создание интерактивных элементов, ES6+.

Адаптивная вёрстка: сайты корректно работают на всех устройствах и во всех браузерах - даже если адаптивность не предусмотрена в макете.

CSS Grid и Flexbox: гибкие и адаптивные макеты.

CSS-препроцессоры: SCSS - модульный и масштабируемый код.

Инструменты сборки: Vite, Webpack - автоматизация, оптимизация, минификация.

CSS-фреймворки: Tailwind CSS - быстрая разработка интерфейсов.

React: компоненты, JSX, хуки, роутинг, работа с REST API.

WordPress и PHP: разработка тем с нуля, кастомизация шаблонов, настройка функционала на PHP, разработка плагинов. REST API, Rewrite API, WP_Query, $wpdb, HTTP API, WordPress Hooks (actions & filters). Принципы OOP. Кастомные Gutenberg-блоки. Composer autoloading (PSR-4).

Docker: создание и управление контейнерами, изолированные среды для разработки и тестирования.

Git и GitLab CI: контроль версий, автоматизация сборки, тестирования и деплоя.

Хостинг и деплой: настройка хостинга, SSL, управление доменами/DNS, деплой (shared hosting, VPS).
